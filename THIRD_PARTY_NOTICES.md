## Open-source library versus paid Pro material

`@heroui/react` is the open-source component library, distinct from the Pro component/template product. This checkout declares the predecessor package `@nextui-org/react` in [frontend/package.json](frontend/package.json); the locked installed version is 2.4.6, whose package metadata declares MIT and whose distributed LICENSE names “Copyright (c) 2020 Next UI.” The installed package's license and notices remain applicable; this statement is specific to that dependency version, not all future library versions.

Using or importing ordinary library primitives such as `Button`, `Card`, or `Textarea` does **not** make an application file Pro-derived. Conversely, installing an open-source library does not relicense a copied paid template built from those primitives. Pro-derived portions require their own provenance assessment even after extensive editing or renaming.

The root package's `SEE LICENSE IN LICENSE` metadata points to this mixed scope. The separate `headless-api` package's existing ISC declaration is unchanged; no HeroUI Pro provenance was established there in this review.
